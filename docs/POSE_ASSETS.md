# 官方姿势资产 · MMR（0.6.0）

使用 Blender 官方资产库保存、分类和浏览缩略图，由 MMR 整理 FK 控制并应用到目标体型。Blender 5.2；无需更换现有 MMR 骨架。

## 保存和使用

1. 选中 MMR 生成的控制骨架，N 面板 → **MMR → 官方姿势资产 · MMR**。物体模式和姿态模式都可用。
2. 点击 **保存 FK 姿势资产**，填写名称与分类。可以从 IK 或 FK 姿势保存，四肢的 IK/FK 滑杆应处于端点 0 或 1。
3. 点击 **浏览官方姿势资产**，在自动打开的官方资产浏览器里查看 **MMR Poses** 库，使用原生缩略图、分类和搜索。
4. 选中姿势，点击浏览器顶部 **MMR · FK 应用**，或右键 **MMR · FK 应用姿势**。使用本插件按钮才能进行完整的跨体型处理。
5. 需要调手脚接触位置时，回到 MMR 面板点击 **对齐并切到 IK**，再拖动手脚控制器。

默认目录位于 Blender 用户数据目录的 `datafiles/MMR/PoseAssets`，不在插件安装目录内。可在面板指定另一目录；首次保存或浏览会自动注册为官方资产库并保存偏好。每个姿势保存为独立 `.blend`，分类写进同目录的 `blender_assets.cats.txt`。同名再次保存会产生独立新文件，不覆盖旧姿势。缩略图是根据实际姿势渲染的骨架人形，资产文件不包含角色网格或其贴图。

保存过程临时匹配为 FK，完成后恢复原来的姿势、IK/FK 状态、旋转模式和自动插帧开关。应用支持 Undo，不插入时间轴关键帧、不替换当前 Action。

## 跨体型的处理范围

- 保存躯干、四肢 FK、肩、头颈、手指和脚趾的支持控制；排除 DEF/ORG/MCH、IK 目标、表情、身体 morph 与普通体型缩放。
- 肢体 FK 控制上的临时位移与拉伸清为 0/1，防止上一个姿势残留；静止骨架比例、根骨位置与根骨缩放保持目标角色现状。用 FK 控制缩放制作的特殊体型不属于此通用资产约定。
- Center／Groove／torso 等身体位移按来源与目标静止身高比例适配；这不是接触约束求解，手扶腰、跪地等仍需 IK 微调。
- 保存手指 master 的 Y 缩放（Rigify 用它卷曲手指）以及必要的 FK/头颈跟随属性，避免误删实际动作。
- 不同 Rigify 静止轴、控制器布局或约束设计不保证互通。缺骨骼、未加载 Rig UI、混合 IK/FK、未整理的旧资产会明确报错。
- 当前为全身姿势应用，不受偶然选中的一根骨骼限制；应用后恢复原选择。

插件读取当前角色生成的 Rigify UI 中的匹配参数，不使用猜测的 IK 骨骼名称。切换 IK 后校正旧 UI 的匹配残差，并检查关节位移与旋转；失败时恢复整次操作前状态。约束无法表达的 FK 姿势不会强行套成另一个姿势。

## 已有姿势

旧 JSONL 姿势库保留在折叠面板中。将旧姿势应用到原本保存它的角色，确认姿势正确，再点 **保存 FK 姿势资产**。原始 Blender 姿势资产也可先在来源角色正常应用，再由此入口保存；不直接把任意旧资产标为“跨体型兼容”。

## 验证

`test_pose_assets.py` 在后台生成三种比例的真实 Rigify 控制骨架，验证 IK 保存恢复、同一资产跨比例应用、FK 肢体残留清理、根骨与静止骨架保留、匹配后 IK 切换、资产重载与注册注销。另以用户已有 `Genesis 9_Rig` 检查 MMR 生成的旧 Rig UI。数值通过不代替日常界面手感和姿势观感验收。
